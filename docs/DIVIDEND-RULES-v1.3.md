# 930955 中证红利低波动100估值温度计：v1.3 弹性定投研究规范

更新日期：2026-09-28。行情冻结至2026-09-17。本版将MA250纳入新增资金的0～4倍规则，并允许停投储备以后再次投入。v1.2保留存档；原输出不覆盖。本规则用于历史研究，不自动生成实盘买入指令。

## 1. 角色与资金约束

家庭安全垫及已确认资产配置 → 红利子账户预算 → 固定定投基准与联合规则比较 → 人工复核。保留家庭现金/货币类至少40%且至少100万元、股票ETF约20%、固收约10%、私募及激励不超过25%的既有框架；未核对最新持仓，不据此计算新增实盘金额。家庭10%回撤为复核线，不是机械止损。

主研究每月入账1万元、无初始储备；该金额只为可缩放单位。每月预算一致，停投款保留，下一次可用。目标买入=基础额×倍数，实际买入=min(目标买入,已有现金＋当期预算)，买入费0.03%包含在实际买入额中。不卖出、不借贷，不在资金不足时补充未记账资金。0倍为停投，不为清仓。主现金利息0%；2%利息与共同12万元初始储备只作敏感性检查。

## 2. 指标口径

PE就是市盈率，采用中证官网历史行情接口peg字段对应滚动市盈率，不按通常PEG解释；不声称等同于总市值加权PE-TTM，不拼接其他PE口径。收益载体为H20955全收益指数。



P_t为930955价格指数收盘点位，TR_t为H20955全收益指数收盘点位。定义Q_t=TR_t/P_t。
令s为t向前一个日历年当天或之前最近的有效交易观察日：

```text
DY_proxy_t = 100 × [(TR_t/TR_s) / (P_t/P_s) - 1]
           = 100 × [Q_t/Q_s - 1]
Spread_proxy_t = DY_proxy_t - CN10Y_t
```

DY_proxy和CN10Y均为百分数，例如4.5表示4.5%，差值为百分点。

不能直接把TR_t/P_t-1当年股息率；不同指数的点位基数不影响上述比值的增长率。也不使用“全收益涨幅减价格涨幅”代替上述公式。

该代理反映一年内分红再投资累积贡献，沿用指数实际成分及权重，带有复利效果。它不等于当前成分股过去12个月现金红利/当前总市值，不保证随当前价格上涨而同步下降。原1.5/2.3/3.0阈值迁移后经济含义发生变化，结果必须结合敏感性检验看待。

全收益指数已经包含分红，账户收益计算不得再次额外加上DY_proxy。该指标也不是可直接提取的现金分红率。


PE与分红代理分位采用截至当日的扩展历史中间秩：100×(小于当前值个数＋0.5×等值个数)/有效样本数；两者各需756个有效观察。国债仅以前值向前延续，不用未来值填补。

## 3. MA250

价格MA250=最近250个有效日930955收盘均值（含当日）。偏离度=100×(价格/MA250−1)，单位百分比；方向=100×(MA250/20个有效日前MA250−1)。不足250日不输出，方向至少需要270日。均线衡量价格位置，不代表内在价值；低于均线不能独立证明便宜。

H20955单独计算自身MA250用于除息影响敏感性检查，不将价格指数除以全收益均线。默认正式研究规则使用价格MA250，另一口径不混入默认交易。

## 4. 新增资金倍数规则

以下“PE≥80”等表述均指PE历史分位，不是PE倍数；代理利差单位为百分点。边界严格按不等号执行。



- 固定定投：每月1倍；全额可用现金投入作为储备场景额外基准。
- 旧温度计：原v1.1信号，但采用本次共同预算及允许储备再投入的新资金模型。
- MA250单指标：偏离≥10%停投；≥5%投0.5倍；>-5%投1倍；>-10%投2倍；>-15%投3倍；否则4倍。低于均线只代表价格位置，不是内在价值。
- PE单指标：PE分位≥80停投；≥60投0.5倍；≥40投1倍；≥20投2倍；≥10投3倍；<10投4倍。
- 联合指标（主候选）：从MA规则开始；PE≥80停投；PE≥60最多1倍；PE<40且偏离≤-5%且代理利差≥1.5百分点至少3倍；PE<20且偏离≤-10%且代理利差≥2.3百分点设4倍；若代理利差<0或分红代理分位<20，最多1倍。停投优先，不以其他条件覆盖。最大4倍。
- 联合+趋势保护：联合指标基础上，若MA250较20交易日前下降，最多2倍。

PE及分红代理分位沿用至少756个有效历史观察；PE未成熟时，PE单指标回退1倍，联合指标回退MA单指标。任何实际信号的当前PE缺失/非正则相关策略停投并记原因。MA未成熟则回退1倍。t日信号最早t+1执行。


旧温度计规则用于对照：利差<1.5投0倍，1.5至<2.3投1倍，2.3至<3.0投1.5倍，≥3.0投2倍；分位成熟且分红代理分位<20或PE分位>80时上限1倍。它沿用旧信号，但资金模型统一为本版。联合规则的PE停投边界为≥80，优先于其他加倍规则。

## 5. 数据与执行时点



正式执行样本从2017年6月首个交易日开始，指数发布日2017-05-26之后；历史行情补到2013年作为计算和预热数据。发布前部分属于回溯数据，仅用于预热，不宣称可实盘交易。

月初首个有效交易日收盘买入，使用前一个有效交易日的收盘信号。国债按此前已公布曲线向前延续，绝不使用未来数据。指数日终字段假定在下一交易日收盘前已发布，缺少逐条历史发布时间验证，是回测限制。

官网历史接口在请求起点为休市日时可能产生边界补值。本次明确剔除2013-01-01和2016-09-18；其余日历使用官方两指数一致的交易记录并检查无周末。未用独立交易所完整日历逐日核验，原始响应保留供复查。


## 6. 验证设计与解释

完整分位主区间2020-07-01起，补充2017-06起含预热全区间；前后段分别独立从零资金开始。比较账户XIRR、时间加权最大回撤、现金比例与实际加倍次数，不单看已投资部分收益。既往已接触全部历史，分段不叫严格样本外。

108组邻域检验：MA停投8/10/12%，低位阶梯4/5/6个百分点，PE停投75/80/85，倍数上限2/3/4/5。另检验现金年息2%、买入费0.10%、共同初始储备12万元、全收益自身均线、额外延迟一天、周频。所有场景内部资金假设一致；储备场景增加全部现金立即投入基准。禁止挑选历史最优参数替换默认。
