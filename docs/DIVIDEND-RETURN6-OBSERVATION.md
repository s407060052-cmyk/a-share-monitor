# 红利低波100近半年累计涨跌幅分位观察 v1.0

本指标是红利页的独立观察信号，不属于 `DIVIDEND-RULES-v1.3.md` 的定投倍数规则。它不改写联合候选、固定定投或趋势保护版，也不自动产生交易或卖出底仓。

## 数据与计算

- 输入是中证930955**价格指数**的交易日收盘点位。H20955全收益指数不用于本指标；价格指数涨跌幅不含分红再投资效果。
- 对观察日`t`，先取六个日历月前的对应日期，月末不足同号日时取该月最后一天；用该日或之前最近一个实际交易日的930955收盘点位作比较起点。若起点早于目标日超过14天，视作输入有缺口，不输出该日半年涨跌幅。
- 累计涨跌幅＝100×（`t`日价格指数÷比较起点价格指数－1），单位为%。
- 历史分位的比较样本，是从可用历史起至`t`日每个交易日按同口径计算的有效半年涨跌幅；只包含当日及以前，使用包含当日的中间秩（并列值取平均名次）。至少756个有效半年涨跌幅观察才判定信号。发布前回溯历史用于计算和预热，应谨慎解释。

## 独立观察信号

| 半年涨跌幅历史分位 | 页面提示 |
|---|---|
| ≤10% | 强烈买入信号 |
| >10%且≤20% | 低估买入信号 |
| >20%且<80% | 中性观察 |
| ≥80%且<90% | 高估卖出信号 |
| ≥90% | 清仓信号 |

历史日期只展示当时可知的历史信号。核心数据未更新、日期不一致或取数失败时撤下当前信号，保留已取的历史数值。指标仅说明**近半年价格变化在历史中的位置**：较低分位不等于内在价值低估，较高分位不独立证明需要卖出或清仓。任何交易判断仍需核对分红、估值、预算和持仓。
